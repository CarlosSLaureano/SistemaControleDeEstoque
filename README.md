# 🛒 Gestor360 - Sistema de Controle de Estoque em MVC

Este projeto é um sistema moderno de controle de estoque em desenvolvimento com **.NET 8** e **SQL Server**, seguindo a arquitetura **MVC (Model-View-Controller)**.

O sistema conta com um design **Premium (Nível Enterprise)**, com efeitos de *Glassmorphism*, animações fluidas e alta usabilidade para proporcionar a melhor experiência de usuário.

## 🔑 Funcionalidades
- 📊 **Dashboard Interativo** – Painel de controle na página inicial com atalhos rápidos e resumo das principais métricas do sistema.
- 📦 **Gerenciamento Inteligente de Estoque** – Adicione, edite e remova produtos e clientes com facilidade através de formulários dinâmicos.
- 👥 **Cadastro de Clientes** – Inclui número de WhatsApp clicável para contato direto.
- 👤 **Controle de Usuários com Perfis** – Apenas administradores podem gerenciar usuários. O perfil padrão possui acessos restritos.
- 🔑 **Redefinição de Senha Segura** – Permite recuperação e alteração de senhas (criptografadas via GerarHash) e admin pode redefinir senha de outros usuários.
- 🗃️ **Listagem e Exportação em Excel** – Produtos, clientes e registro de atividades podem ser exportados por período.
- 📝 **Registro de Atividades (Logs)** – Cada ação é registrada e pode ser consultada por período e exportada somente pelo Admin.
- 🚀 **Interface Moderna e Limpa** – Design unificado utilizando *Glassmorphism*, menus laterais dinâmicos, formulários iconificados e tabelas limpas.
- 🚪 **Logout Rápido e Seguro** – O usuário pode sair com um clique da tela principal.
- 💬 **Pop-ups Nativos e Intuitivos** – Ações destrutivas (como exclusão de registros) possuem confirmações elegantes usando *SweetAlert2*.
- ✅ **Feedback e Empty States** – Mensagens claras de validação (sucesso/erro) e telas amigáveis quando não há registros cadastrados.

## 🚀 Tecnologias Utilizadas
- **Back-end:** .NET 8 (C#) e Entity Framework Core
- **Banco de Dados:** SQL Server
- **Arquitetura:** MVC (Model-View-Controller)
- **Front-end / UI:** HTML5, CSS3 avançado (Glassmorphism), JavaScript
- **Bibliotecas Visuais:** Bootstrap 5, FontAwesome (Ícones), DataTables (Tabelas Interativas), SweetAlert2 (Pop-ups)
- **Outros:** jQuery
